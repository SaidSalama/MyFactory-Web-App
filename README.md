# MyFactory-Web-App
A web based application that is used for managing factory, monitoring and controlling the machines of the factory in real time and many other functionalities 

A modern, real-time **Factory Management System** with role-based access control, built with React + TypeScript + Vite.

## 🎯 Project Overview

MyFactory is a comprehensive industrial dashboard designed to help factories monitor and control production in real time. It supports three user roles with tailored interfaces:

- **Engineer**: Machines, Sensors, Demands, Tasks, HMI
- **Technician**: Machines, Sensors, Tasks, HMI
- **Director / Business Owner**: Machines, Sensors, Demands, Tasks, Admin , AI assistant

## ✨ Key Features

- **Role-Based Authentication & Authorization** using JWT
- **Secure Password Handling** with bcrypt encryption
- **Real-time Monitoring** of machines, sensors, and production
- **HMI Control Panel** with Start/Stop/Reset functionality and live timers
- **AI Assistant** (integrated with n8n) to generate tasks and demands
- **Admin Panel** for managing users, machines, and sensors
- **Responsive Industrial UI** – works on desktop, tablet, and mobile factory devices

## 🛠 Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Authentication**: JWT (JSON Web Tokens)
- **Password Security**: bcrypt
- **Backend Integration**: n8n workflows (see screenshots)
- **Styling**: Pure CSS (custom industrial blue-steel theme)
- **Icons**: Lucide React
- **Routing**: React Router
